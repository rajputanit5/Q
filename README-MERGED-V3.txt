NEET Answer Noting V3 — Merged Objective + Subjective

At setup, choose:
1. Objective / OMR — keyboard 1-4 selects answers.
2. Subjective — type answers; Enter moves next, Shift+Enter makes a new line.

Both modes retain the same UI and core features:
- Up to 200 questions
- Custom timer
- Auto-save
- Question palette
- Mark for review
- Dark mode
- Final review
- Correct/Incorrect checking: 1 / 2 / Enter
- Unattempted questions skipped during checking
- PDF export
- GitHub Pages/PWA assets and icons

Upload all files to the root of your GitHub Pages repository.

ICON FIX: manifest, favicon.ico/png, Apple Touch Icon, and PWA meta tags are included. If GitHub Pages previously cached the old PWA, uninstall the old app and reinstall after deployment.
